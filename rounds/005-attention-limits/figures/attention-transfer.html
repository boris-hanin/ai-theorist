Reading these

The learning-rate rule was derived from the architecture before being tested — the width factor from requiring δf = Θ(1) at the μP readout, the depth factor from summing L residual blocks each moving the stream by η β₀² L^(−2α_L). It lands on the paper's Table 1 exactly. Each control then removes precisely one factor that derivation predicts, so a control that still transferred would mean the sweep cannot see that factor at all.

The bottom row is not evidence. At α_L = 1/2 the depth factor L^(2α_L−1) is L⁰ — the identity — so its control cannot change anything by construction. It is here as a consistency check on the harness, and the two panels agreeing to three decimals is that check passing.

Both attention exponents transfer. The first two rows sweep width at α_A = 1 and α_A = 1/2, and both hold. That was predicted in advance: any α_A can be made to give Θ(1) attention updates by rescaling the learning rate, so a transfer sweep cannot discriminate it. The observable that does is the across-head variance of the attention logits, which is a different experiment.

A verdict of “transfers” requires the optimum drift to be under 0.3 decades and the optimum to be located separately per seed so its across-seed scatter is measured. An optimum sitting on the edge of the swept grid is reported as under-powered, not as a pass — the first run of this sweep did exactly that, and the grid was widened until every optimum sat inside it.
